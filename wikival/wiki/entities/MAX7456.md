# MAX7456

## What It Is

A **monochrome on-screen-display controller IC** originally from
Maxim Integrated (now Analog Devices). It composites character /
graphics overlays onto an analog NTSC or PAL video signal in real
time. The character set is stored in on-chip NVM and is field-
programmable.

The MAX7456 is the on-FC OSD chip used for **analog FPV video** on
essentially every Betaflight FC built since ~2016.

## Role in Betaflight Ecosystem

- Sits in the analog video path **between the camera and the VTX**.
- The MCU pushes character positions and attributes to the MAX7456
  over **SPI**.
- The MAX7456 composes the final video signal the VTX transmits.
- Digital VTX systems (DJI O3, Walksnail, HDZero) **bypass the MAX7456
  entirely** — they get OSD over MSP DisplayPort UART instead.

Driver: `src/main/drivers/max7456.c`. Higher layer: `src/main/io/osd.c`.

## AT7456E (the clone)

**AT7456E** is a Chinese-made pin-compatible clone widely used on
budget BF FCs. Functionally identical from the firmware's
perspective — same SPI register map, same NTSC/PAL handling. Some
versions have a different default character set or font upload quirk
but BF handles both with the same driver.

## Key Facts

| Fact | Value |
|------|-------|
| Vendor | Analog Devices (was Maxim) |
| Type | Monochrome OSD controller, analog NTSC/PAL |
| Bus | SPI (up to 10 MHz) |
| Voltage | 5 V analog, 3.3 V digital |
| Character grid | 30 × 13 (NTSC), 30 × 16 (PAL) |
| Character set | 256 chars, 12×18 px each, replaceable NVM |
| BF status | Tier-1, default analog OSD chip |
