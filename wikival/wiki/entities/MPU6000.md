# MPU6000

## What It Is

A **6-axis MEMS IMU** (3-axis gyro + 3-axis accelerometer) from
Invensense (now part of TDK). Originally released ~2011, it became
the de-facto standard for hobby FCs and stayed there for a decade.

Was **discontinued by Invensense** and went through years of supply
crunch — Chinese FC manufacturers paid premium prices for grey-market
stock. **Recently returned to production** (per official BF docs as
of 2026-05-12).

## Role in Betaflight Ecosystem

- The reference IMU. Default tuning numbers in Betaflight historically
  targeted MPU6000 behavior.
- Boards that ship with MPU6000 generally need no filter retuning out
  of the box.
- Older Configurator support is rock-solid; every BF release since 1.x
  has had MPU6000 drivers.

Driver: `src/main/drivers/accgyro/accgyro_spi_mpu6000.c`.

## Key Facts

| Fact | Value |
|------|-------|
| Vendor | Invensense (TDK) |
| Type | 6-axis IMU (gyro + accel) |
| Max gyro sample rate | **8 kHz** |
| Bus | SPI (also I²C variant: MPU6050) |
| Voltage | 3.3 V |
| BF status | Tier-1 supported, the gold standard |
| Production status | Returned to production (2026) |

## Pin-compatible siblings

- **MPU6050** — I²C version of the same die.
- **MPU9250** — adds a magnetometer (9-axis); rarely used on BF.
- **ICM-20602 / ICM-20689** — drop-in successors from same vendor.
